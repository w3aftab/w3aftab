- MongoDB-backed CRUD workflows and data models

## Featured Projects

### [DailyNotes](https://github.com/w3aftab/mern-daily-notes)

A full-stack note-taking application built with React and Express. It includes note creation, detail pages, editing, deletion, MongoDB persistence, React Router navigation, toast feedback, and deployment configuration.

`React` `React Router` `Express` `MongoDB` `Mongoose` `Axios` `Vite`

### [Products CRUD with ExpressJS and MongoDB](https://github.com/w3aftab/Products_CRUD_with_ExpressJS_MongoDB_HTML)

A product administration interface with a browser-based frontend and an Express/MongoDB backend. The project supports product CRUD operations, name search, maximum-price filtering, sorting, product details, and image assets.

`HTML` `CSS` `JavaScript` `Express` `MongoDB` `Mongoose` `Fetch API`

### [Default HTML Styling II](https://github.com/w3aftab/default-html-styling-II)

A semantic, class-light HTML theme focused on readable defaults and polished browser-native elements. It includes responsive forms, tables, lists, navigation, validation states, focus styles, and reduced-motion support.

`HTML5` `CSS3` `Responsive Design` `Accessibility`

### [Deployable Express React](https://github.com/w3aftab/Deployable-Express-React)

A reusable starter for building and deploying Express and React applications. It includes an API health endpoint, Vite development proxying, concurrent development scripts, production static serving, SPA fallback routing, and Render configuration.

`Node.js` `Express` `React` `Vite` `Render`
